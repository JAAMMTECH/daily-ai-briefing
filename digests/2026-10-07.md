## AI

### Strands Decider 2B: a small, open-source, decision model

Hacker News

Strands Decider 2B is an open-source 2-billion-parameter model that removes the language-model head and instead picks among supplied options with a calibrated reliability score, answering in tens of milliseconds on a local CPU or GPU. It is built on Qwen3.5-2B with a small pointer head, and the training data and scripts are released.

Why it's worth knowing: Decision models trade text generation for speed and confidence scores, a pattern that could change how agent workflows are built; commenters note it is unclear how to run these locally with llama.cpp and that results on tasks like PDF classification are mixed.

https://strandsagents.com/blog/introducing-strands-decider/
Discussion: https://news.ycombinator.com/item?id=49987076

### EmbeddingGemma 2: An open, lightweight multimodal embedding model

Hacker News

Google released EmbeddingGemma 2, a 740M-parameter Apache 2.0 embedding model that places text, code, images, video and audio in one shared space. It raises MTEB Code from 68.76 to 78.68 and can run in roughly 191MB of RAM for text-only use.

Why it's worth knowing: It makes private, fully on-device multimodal search and retrieval practical on modest hardware.

https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/
Discussion: https://news.ycombinator.com/item?id=49980487

### OpenTPU – An open-source AI accelerator, developed by AI

Hacker News

OpenTPU is an open-source AI accelerator designed largely by AI agents, with SystemVerilog, a simulator, a compiler and host software in one repo. On an older Kintex-7 FPGA card it runs ten small models bit-exact against its simulator, for example about 11 tok/s on LFM2-2.6B.

Why it's worth knowing: It is a readable end-to-end look at how an accelerator works, and a test of how far AI agents can go in hardware design.

https://github.com/FeSens/openTPU
Discussion: https://news.ycombinator.com/item?id=49980715

### Strata: fetch experts before they're needed. Up to +34 % decode headroom measured on 2× 3090, more on smaller-VRAM cards

r/LocalLLM

Strata, a mixture-of-experts inference engine, measured decode speed on 2x RTX 3090 falling from 97 to 68 tok/s as expert cache hit rate dropped from 95% to 81%. The author estimates prefetching experts could add up to 34% decode speed, and more on smaller-VRAM cards.

Why it's worth knowing: It shows that expert cache misses on consumer hardware cost more than they appear to, and that prefetching is a promising fix.

https://www.reddit.com/r/LocalLLM/comments/1wzt4pz/strata_fetch_experts_before_theyre_needed_up_to/

### PSA: Use your iGPU for display to save VRAM

r/LocalLLM

A user running a 27B model with vision on an RTX 4090 moved their display output to the motherboard's integrated GPU, freeing about 2.5GB of VRAM. Context grew from 65k to 132k tokens at 125 tok/s.

Why it's worth knowing: It is a free tweak that helps anyone squeezing a model into limited VRAM.

https://www.reddit.com/r/LocalLLM/comments/1wzpnl3/psa_use_your_igpu_for_display_to_save_vram/

### ggml-org/llama.cpp b11476

GitHub: ggml-org/llama.cpp

llama.cpp build b11476 extends its Metal few-row matrix-multiply kernel to BF16, MXFP4, the Q2/Q3 K-quants and IQ types. Measured on an M3 Ultra, time drops to as little as 0.23 of the previous time for small batches.

Why it's worth knowing: It speeds up small-batch inference on Apple Silicon for many quantization formats.

https://github.com/ggml-org/llama.cpp/releases/tag/b11476

### Vulkan back end coming to SYCL

Hacker News (watchlist)

AdaptiveCpp added a Vulkan backend with Android cross-compilation, letting SYCL code run on almost any Vulkan-capable GPU, including mobile ones. It is tested on Linux, Windows and macOS (via MoltenVK), and the post includes early Android benchmarks and build steps.

Why it's worth knowing: A vendor-neutral compute path through Vulkan widens where portable GPU code can run.

https://adaptivecpp.github.io/hipsycl/adaptivecpp/sycl/vulkan/android/vulkan-android/
