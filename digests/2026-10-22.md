### Compromised LiteLLM 1.107.0 on PyPI Installs a Credential Stealer and Backdoor

Hacker News

LiteLLM 1.107.0 on PyPI was compromised and installs a credential stealer and a backdoor.

Why it's worth knowing: Anyone who installed this version should treat their credentials as exposed and rotate them.

Terms:
- **LiteLLM** — Project name, not an acronym — A Python library and gateway that gives one API interface to many LLM providers. It is widely used to route requests between models.
- **PyPI** — Python Package Index — The main public repository for Python packages installed with pip. Attackers target it because one poisoned release reaches many users.

### macOS 27 has a built-in, offline LLM you can call from Terminal

Hacker News (watchlist)

macOS 27 reportedly lets you call Apple's on-device Foundation Models from Terminal with `fm respond`, structured JSON output via `--schema`, and a local endpoint via `fm serve`. It reportedly runs on M1 Macs with 8GB RAM and a 4K context window.

Why it's worth knowing: A built-in local model could make shell automation possible without API costs or extra installs.

Terms:
- **context window** — Not an acronym — The maximum amount of text, measured in tokens, a model can consider at once. A 4K window is small, so long documents must be split.

https://news.ycombinator.com/item?id=50185265

### 1-bit Bonsai-27B on a 6 GB GTX 1660 SUPER: 18.7 -> 54.3 tok/s (+190%) with a Q1_0 CUDA patch for llama.cpp

r/LocalLLM

A CUDA patch for llama.cpp reportedly raises 1-bit Bonsai-27B from about 19 to about 56 tok/s on a 6GB GTX 1660 SUPER, with matching perplexity and identical greedy output.

Why it's worth knowing: It shows how much speed old GPUs can still gain from format-specific kernels.

Terms:
- **llama.cpp** — Project name, not an acronym. The .cpp means it is written in C++ — An open-source engine for running LLMs locally on CPUs and GPUs, using quantized model files.
- **tok/s** — Tokens per second — The rate at which a model generates output tokens, the usual measure of inference speed.
- **Q1_0** — A llama.cpp quantization format name — A 1-bit format where each weight is +1 or -1, which shrinks the model massively at some cost in quality.
- **perplexity** — Not an acronym — A measure of how well a model predicts text, where lower is better. Matching values suggest the patch did not hurt accuracy.

https://www.reddit.com/r/LocalLLM/comments/1xc2gvw/1bit_bonsai27b_on_a_6_gb_gtx_1660_super_187_543/

Watchlist match.

### 320B model (GLM-5.3-Flash) at ~7 tok/s on an 11GB 2080 Ti, thanks to 256GB of pre-boom RAM

r/LocalLLM

A user reports running the 320B GLM-5.3-Flash at about 7 tok/s on an 11GB RTX 2080 Ti by keeping the MoE experts in 256GB of system RAM via llama.cpp.

Why it's worth knowing: It shows that a huge sparse model can run on modest hardware if you have enough RAM.

Terms:
- **MoE** — Mixture of Experts — A model design where only a few expert sub-networks activate per token, so most weights can sit in slower memory.

https://www.reddit.com/r/LocalLLM/comments/1xbrn6w/320b_model_glm53flash_at_7_toks_on_an_11gb_2080/

Watchlist match.
