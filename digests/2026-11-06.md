### Claude Code sends your email address to websites

Hacker News

A Claude Code bug report says the tool sends the signed-in user's email address to websites inside the User-Agent header. The report, filed as a privacy violation, drew more than a thousand comments on Hacker News.

Why it's worth knowing: Coding agents browse the web while signed in as you. An account email leaking to every site the agent opens is a privacy failure in the client, separate from how good the model is.

Terms:
- **User-Agent** — HTTP User-Agent header — A short string a browser or tool sends with each request to identify the client. The bug report says Claude Code is putting the account email in that string.

https://github.com/anthropics/claude-code/issues/107757

### Show HN: A decent text-to-image model trained for ~$20K (Apache 2.0 Weights)

Hacker News

Two-person lab Linum released Apache 2.0 weights for a text-to-image model trained for about $20,000 on 660 million samples. The model uses their Pyramid-JiT design, which learns in pixel space instead of compressing images with a separate variational autoencoder first.

Why it's worth knowing: They argue that dropping the autoencoder simplifies training, converges much faster, and allows more aggressive compression, which is the cost path they want for video. It is a concrete open release, not only a benchmark claim.

https://www.linum.ai/field-notes/pjit-21k
Discussion: https://news.ycombinator.com/item?id=50368208

### ggml-org/llama.cpp b12167

GitHub: ggml-org/llama.cpp

llama.cpp tagged b12167 today, including a CUDA fix for Maxwell-generation NVIDIA cards and new macOS, Linux, iOS, Vulkan, and CUDA binaries.

Why it's worth knowing: Local runners depend on these small releases. A broken build for older GPUs, or a fresh Vulkan binary, is what decides whether a model actually starts on the machine in front of you.

Terms:
- **CUDA** — Compute Unified Device Architecture — NVIDIA's platform for running programs on its GPUs. This release fixes the build for Maxwell, an older GPU generation.
- **Vulkan** — Vulkan graphics API — A cross-vendor GPU interface. llama.cpp ships Vulkan builds so inference is not limited to NVIDIA's CUDA stack.

### Dense 27B as a local Linux agent: what I did so llama.cpp stops re-reading the whole chat after every tool call

r/LocalLLM

A LocalLLM post on using Qwen3.8 27B as a Linux agent describes the llama.cpp failure mode where a tool call that changes the top of the prompt makes the server reread the whole conversation. On a Radeon 7900 XT the author measured about 32 tokens per second without multi-token prediction, about 60 with it, and about 800 tokens per second of prompt processing.

Why it's worth knowing: Agent use is often limited by prompt processing, not by how fast the model writes the next word. If the cache does not survive a tool call, a dense 27B model feels unusable even when generation speed looks fine.

https://www.reddit.com/r/LocalLLM/comments/1xopnyj/dense_27b_as_a_local_linux_agent_what_i_did_so/

### Qwen3.8 27B FP8 on 4× Radeon AI PRO R9700: 7K tok/s prefill, 814 tok/s C8 decode

r/LocalLLM

A four-GPU Radeon AI PRO R9700 machine, with each card capped at 210 watts, is reported running Qwen3.8 27B in FP8 at about 7,000 tokens per second of prefill and about 814 tokens per second of aggregate decode for eight concurrent users.

Why it's worth knowing: These are measured AMD figures under a normal household circuit limit, not a vendor peak. They give a current comparison point for anyone pricing local throughput against NVIDIA boxes.

Terms:
- **FP8** — 8-bit floating point — A compact number format that cuts memory use so a larger share of the model fits on the GPUs.
- **prefill** — prompt processing — The pass that reads the input before any new tokens are generated. It is usually much faster, in tokens per second, than decoding.

https://www.reddit.com/r/LocalLLM/comments/1xp127a/qwen38_27b_fp8_on_4_radeon_ai_pro_r9700_7k_toks/

### Harness-S: Learning from Sibling Harnesses for Generalizable Agent Training

Hugging Face papers

The Harness-S paper trains an agent by calling in sibling harnesses only after a base harness has already failed, then tries to keep the new behavior once the extra scaffolding is removed. The authors report gains on AppWorld, SWE-Gym, and DBBench over policy-only training.

Why it's worth knowing: A lot of agent skill lives in the scaffold around the model. The result that matters is whether a repair learned under a special harness still shows up when you go back to the original one.

Terms:
- **harness** — agent harness — The tools, retries, and control flow wrapped around a model. Two harnesses can make the same model succeed or fail on the same task.

https://huggingface.co/papers/2611.04277

### VFlash: Fast, Accurate Visual Planning via Flash Primitive Decoding

Hugging Face papers

VFlash predicts an entire visual primitive, such as a bounding box or a trajectory, in one forward pass instead of emitting coordinate tokens one at a time. The authors say this cut prediction error versus ordinary autoregressive decoding on the 2D and 3D robot trajectory tasks they tested.

Why it's worth knowing: Robot and driving models that plan in points and paths get expensive when every coordinate is its own token. The paper's bet is that a structurally valid box or path is enough, even if it does not match the original token sequence.

Terms:
- **visual primitive** — structured spatial prediction — A compact spatial object such as a box or a trajectory, as opposed to a sentence of individual coordinate tokens.

https://huggingface.co/papers/2611.08449

## Ontario and Canada

### Canada to implement QSBS-style tax incentive and ‘level playing field’ with US

BetaKit

Budget 2026 introduces a Canada Growth Incentive, a tax break for entrepreneurs and investors modeled on the U.S. qualified small business stock rules. BetaKit reports it as the federal answer to a long-running request from Canadian tech and venture investors.

Why it's worth knowing: Founders compare after-tax proceeds on a Canadian exit with a U.S. one. A QSBS-style exemption is meant to narrow that gap for people deciding where to incorporate and where early capital sits.

Terms:
- **QSBS** — qualified small business stock — A U.S. rule that can shield some gains on shares in a small company from federal tax. The Canadian measure is designed as a counterpart.

https://betakit.com/canada-to-implement-qsbs-style-tax-incentive-and-level-playing-field-with-us/
