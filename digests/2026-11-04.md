### ggml-org/llama.cpp v0.9.0

GitHub: ggml-org/llama.cpp

llama.cpp v0.9.0 adds FP8 E4M3 weights, a flash_attn_ext_rows operation that makes a unified KV cache practical for multi-sequence inference, and support for four more architectures, including Mistral Large 4. The release also expands audio generation and transcription, and updates the ggml library with multi-node tensor parallelism on CPU and GPU backends.

Why it's worth knowing: This is the build that decides which new open models and number formats a local runner can actually load.

Terms:
- **llama.cpp** — Project name, not an acronym. The .cpp means it is written in C++. — A C++ engine that runs open-weight language models from a single file on CPUs and on GPUs. Local apps that load GGUF weights usually sit on top of it, with backends for CUDA, Metal, Vulkan, and several other APIs.
- **FP8** — 8-bit floating point — A way of storing a real number in one byte instead of the two bytes of FP16 or the four of FP32. Model weights in this format move less data through memory, which is often what limits generation speed on a local GPU.
- **E4M3** — 1 sign bit, 4 exponent bits, and 3 mantissa bits — The layout of an 8-bit float used by the Open Compute Project. Four exponent bits set how large a number can be, and three mantissa bits set how finely it is spaced. It favors precision over range compared with the E5M2 alternative.
- **KV cache** — key-value cache — The keys and values a transformer stores for tokens it has already processed. Reusing them lets the model produce the next token without rerunning the whole prompt. A unified cache puts several conversations in that same pool, which saves memory and needs an attention kernel that can index individual rows.

### AI is forcing us to pay off 40 years of technical debt

Hacker News

A memory bug in PHP, filed as a crash since 2024, was turned into a way to read data and run code on servers that host WordPress, Drupal, and other PHP sites, including NASA, Wikipedia, and the White House. A Calif researcher using AI tools found that path within two weeks of an OpenAI-sponsored audit, and a four-person PHP Foundation team spent two months on a patch that shipped before, as far as the report can tell, anyone exploited it.

Why it's worth knowing: The models did not replace the specialist. They made the tedious memory reasoning fast enough that an ignored crash became a working server takeover.

Terms:
- **PHP** — PHP: Hypertext Preprocessor. It originally stood for Personal Home Page. — A language that runs inside the web server and builds pages for WordPress, Drupal, and a large share of older sites. Because the interpreter and the site share one process, a memory error in PHP can become control of the host, not just a crashed request.

### Nvidia RTX Spark encrypted firmware slows inference speed to 35% on Linux

Hacker News

Native Linux on Nvidia RTX Spark laptops locks the GPU to about 780 MHz on wall power, against roughly 2.2 GHz on Windows, because the firmware power table is encrypted and only the Windows driver can read it. On GPT-OSS-120B that is 13.9 tokens per second on Linux, versus 65.4 on Windows and 65.1 under WSL, which still uses the Windows driver.

Why it's worth knowing: The laptop is being sold for local models, and a normal Linux install currently gives up most of the speed the chip is rated for.

Terms:
- **RTX Spark** — Product name, not an acronym. — Nvidia's laptop version of the Spark platform, used in machines such as the MSI Prestige. The CPU and GPU share a large pool of memory, which is why these laptops are aimed at people running big local models.
- **GPT-OSS** — Product name. OSS here refers to open weights, not a standards-body format. — OpenAI's family of open-weight language models, published so they can run outside OpenAI's own API. The 120-billion-parameter size is large enough that memory bandwidth and GPU clocks dominate how fast it generates.
- **token** — Not an acronym. — The piece of text a language model actually reads and writes, often a word or a fragment of a word. Tokens per second, measured after the prompt has been processed, is the usual figure for generation speed.
- **WSL** — Windows Subsystem for Linux — A Windows feature that runs Linux programs on a Windows machine. In this setup it calls Nvidia's Windows GPU driver rather than the Linux kernel driver, so the encrypted power table is still applied and the chip can boost.

https://www.mindstudio.ai/blog/linux-nvidia-rtx-spark-laptop

### Running quantum circuits inside llama.cpp

Hacker News (watchlist)

qullama stores a quantum circuit as a GGUF file whose layers are the gates, then a small llama.cpp patch runs that file so the output embedding is the circuit's statevector. The author calls it a proof of concept, with Vulkan and CUDA kernels and optional quantized gate weights, and says it still needs testing before it is useful.

Why it's worth knowing: The interesting part is the reuse: a language-model runtime is being driven as a circuit simulator, not as a chatbot.

Terms:
- **qullama** — Project name, not an acronym. — A proof-of-concept tool that writes quantum gates into the same file format llama.cpp uses for neural-network weights. Running that file applies the gates to an initial quantum state instead of predicting the next token.
- **GGUF** — GPT-Generated Unified Format — The binary file llama.cpp loads. Weights, tokenizer, and metadata sit in one file, so the runtime does not need a training framework such as PyTorch to execute the model. Here the same container holds gate matrices instead of neural-network weights.
- **Vulkan** — Name, not an acronym. It is the Khronos Group's GPU API. — A cross-vendor interface for graphics and general-purpose computation on GPUs. The same shaders can run on AMD, Nvidia, and Intel hardware, which is why portable model runtimes offer it alongside CUDA. This project uses it to apply quantum-gate matrices.
- **statevector** — Not an acronym. — The full list of complex amplitudes that describes a quantum register. For n qubits there are 2^n amplitudes. Applying a gate multiplies that vector by the gate's matrix, which is the calculation this file format is set up to perform.

https://github.com/dakk/qullama

### Low cost $1500 AI rig - QWEN 3.8 Flash Next, 52.5 t/s decode in FP8 - 6xM10 = 192GB VRAM

r/LocalLLM

One LocalLLM build stacks six used Nvidia Tesla M10 boards, about $80 each, into a roughly $1,500 rig with 192 GB of video memory. The author reports 52.5 tokens per second decoding Qwen 3.8 Flash Next in FP8, from the combined bandwidth of the 24 older GM107 chips on those cards.

Why it's worth knowing: It is a measured counterexample to the idea that only a new GPU can serve a large model, with the bandwidth coming from many old chips ganged together.

Terms:
- **Tesla M10** — Product name, not an acronym. — An older Nvidia server board from the Maxwell generation. Each card puts four small GM107 GPUs and 32 GB of memory behind an onboard PCI switch. Six of them are how this build reaches 192 GB.
- **Qwen** — Model family name, not an acronym. — Alibaba's series of open-weight language models, released in many sizes so a small one can run on a laptop and a larger one on a multi-GPU server. Flash Next is one of the faster, smaller variants in the current line.

https://www.reddit.com/r/LocalLLM/comments/1xnl82r/low_cost_1500_ai_rig_qwen_38_flash_next_525_ts/
