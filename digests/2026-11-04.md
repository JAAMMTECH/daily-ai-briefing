### Nvidia RTX Spark encrypted firmware slows inference speed to 35% on Linux

Hacker News

On RTX Spark laptops such as the MSI Prestige, Linux boots and Nvidia's open kernel driver gives GPU acceleration, but on wall power the GPU sits near 780 MHz instead of about 2.2 GHz on Windows. The power table is encrypted, and only the Windows driver can read it. On GPT-OSS-120B that is 13.9 tokens per second on native Linux, against 65.4 on Windows, 65.1 under WSL, and 61 on a DGX Spark desktop. Commenters call this missing Linux support for Windows-laptop firmware, not a ban on Linux inference, and note Nvidia has shipped similar power-sharing on Linux years later.

Why it's worth knowing: Installing Linux directly on these laptops gives up most of the inference speed. WSL still gets the Windows boost.

Terms:
- **RTX Spark** — Product name, not an acronym — Nvidia's laptop platform, used in machines such as the MSI Prestige, Asus ProArt, and Dell XPS. It shares a GPU design with the DGX Spark desktop, but the laptops ship with Windows on ARM.
- **WSL** — Windows Subsystem for Linux — A Windows feature that runs Linux programs on top of the Windows kernel. Here it also uses the Windows GPU driver, so the card still boosts.
- **GPT-OSS-120B** — Model name, not an acronym — The open-weight model used as the speed test in this writeup. The 120B is its parameter count, about 120 billion learned weights.
- **DGX Spark** — Product name, not an acronym — Nvidia's small desktop machine built around the same GPU design. Unlike the laptops, it ships with Nvidia's own Linux image.

### AI is forcing us to pay off 40 years of technical debt

Hacker News

IEEE describes PHP2Shell as a PHP out-of-memory bug reported in 2024 and left alone because it only crashed. During an OpenAI-sponsored audit, a Calif researcher using AI tools turned that crash into remote code execution in about two weeks. Wiz confirmed the bug and widened it. A patch landed before the researchers knew of anyone exploiting it. Columbia's Suman Jana says the hard part is tedious, exact reasoning about memory, which the tools speed up, and that the people doing the work still needed deep PHP and security knowledge.

Why it's worth knowing: A crash report that sat for two years became a critical server bug once AI-assisted auditing made the exploit practical to build.

Terms:
- **PHP2Shell** — Name of the vulnerability, not an acronym — A bug in PHP, a language widely used by older websites including WordPress and Drupal. An out-of-memory crash was shown to be steerable into running an attacker's code on the server.

### ggml-org/llama.cpp v0.9.0

GitHub: ggml-org/llama.cpp

Tagged today, llama.cpp v0.9.0 adds an Open Compute Project FP8 E4M3 weight type, a flash_attn_ext_rows operation that makes the unified KV cache efficient when several sequences run at once, and a batched tensor-copy API. New architectures are Clover, Limite, Metis-1.6, and Mistral Large 4. Speech support grows with Chatterbox text-to-speech, Nemotron 3.5 Transcribe, and Pocket TTS voices, and Gemma 4 E2B and E4B get large speedups while processing the prompt. The bundled ggml update, v0.29.0, includes Vulkan work and the other GPU backends, plus multi-node tensor parallelism.

Why it's worth knowing: This is the local inference engine on the watchlist, and the tag changes which quantized models and multi-user setups it can run well.

Terms:
- **llama.cpp** — Project name, not an acronym. The .cpp means it is written in C++ — An open-source engine for running language models locally on CPUs and GPUs. This note is the project's own release, not a third-party repack.
- **FP8** — 8-bit floating point — A compact number format, half the width of 16-bit floats, used to store model weights so more of a model fits in memory. This release adds the Open Compute Project E4M3 variant in saturating mode.
- **E4M3** — 4 exponent bits and 3 mantissa bits — The layout of that 8-bit float: four bits set the range and three set the precision. It is a weight format, not a new model.
- **KV cache** — Key-value cache — The stored attention keys and values for tokens the model has already read. Reusing them avoids redoing the prompt for every new token. The new operation makes one shared cache layout faster when several sequences are in flight.

https://github.com/ggml-org/llama.cpp/releases/tag/v0.9.0

### Flash-Next vs 27B vs Sonnet 5.5 on 5 agentic coding tasks: both locals match Sonnet on the spec, neither comes close on what the spec doesn't say

r/LocalLLM

The poster ran Flash-Next, a 27B local model, and Sonnet 5.5 on five coding tasks with the same prompts, a fresh session each time, and no help along the way. About 185,000 checks were applied by scripts, not by the models' own tests, across an expression parser, bug fixes with hidden bugs, an invoice refactor, a REST API, and a kanban board. The 27B passed every spec check and Flash-Next finished 2.2 times faster, but both left three to seven times as many robustness holes as Sonnet on cases the spec never stated.

Why it's worth knowing: A local model can clear the tests you wrote and still miss the cases you forgot to write down.

Terms:
- **Sonnet 5.5** — Model name, not an acronym — Anthropic's Claude Sonnet 5.5, the hosted model used as the comparison point in this test.
- **Flash-Next** — Model name, not an acronym — The faster of the two local models in the writeup. The excerpt does not give it a longer product name.
- **27B** — 27 billion parameters — Shorthand for the size of the other local model. A parameter is one learned weight. The post says this model passed every stated spec check.

### Low cost $1500 AI rig - QWEN 3.8 Flash Next, 52.5 t/s decode in FP8 - 6xM10 = 192GB VRAM

r/LocalLLM

A LocalLLM user reports a roughly $1,500 build of six used Nvidia Tesla M10 cards, at about $80 each, totaling 192 GB of VRAM. It runs Qwen 3.8 Flash Next in FP8 at 52.5 tokens per second decode. Each M10 is four GM107 chips with 8 GB and about 83 GB/s of bandwidth, which the author adds up to about 1,992 GB/s across the six cards. The build notes are at github.com/crgregersen/m10dis. The post says the usual advice is that these cards are not usable for AI.

Why it's worth knowing: It is a measured, if unconventional, data point for a large local model on cheap older datacenter GPUs.

Terms:
- **Qwen** — Model family name, not an acronym — Alibaba's series of open-weight language models. Qwen 3.8 Flash Next is the checkpoint this build ran, stored in 8-bit floating point.
- **Tesla M10** — Product name, not an acronym — An older Nvidia server GPU. Each card holds four small GM107 chips and 32 GB of memory, so six cards are the 192 GB in this build.
- **decode** — Not an acronym — The stage where a model emits output tokens one by one. It is usually limited by how fast weights can be read from memory, which is why the author adds up bandwidth.

### Think Less, Locally: Local Preference Learning for Reasoning Compression

Hugging Face papers

LoCo tries to stop a reasoning model from continuing after it already has enough to answer. It finds those points in the model's own traces, freezes the prefix, generates a shorter continuation that still checks out, and trains with DPO on that pair. On the authors' tests, completion length fell by 41.7 to 45.4 percent on math and 23.4 to 36.3 percent on code, with accuracy held or improved. The training data came only from the model's own math traces.

Why it's worth knowing: Shorter reasoning helps only if the model learns when to stop, rather than being pushed to be brief on every problem.

Terms:
- **LoCo** — Name of the method in this paper. The excerpt does not give a letter-by-letter expansion — Local preference learning. At a given intermediate state, the model is trained to prefer a shorter verified continuation over more deliberation.
- **DPO** — Direct Preference Optimization — A training method that nudges a model toward a preferred answer and away from a rejected one without a separate reward model. Here the pair is a shorter checked continuation versus more reasoning, from the same prefix.

https://huggingface.co/papers/2611.04814
